# Why runx Matters for AI Agent Development

runx is an open-source project that provides governed execution, portable skills, and receipt-verified work for AI agents. In a world where AI agents increasingly do real commercial work, the ability to verify what an agent actually did — with cryptographic receipts — is essential.

## What runx does

- **Governed execution**: Every step an agent takes is recorded and verifiable
- **Portable skills**: Agent skills defined in SKILL.md files are portable across platforms
- **Receipt integrity**: Each action produces a sealed receipt that can be independently verified
- **Open source**: Available at https://github.com/runxhq/runx

## Why this matters

As someone building AI agents that do real work (like the Approval Risk Auditor), I need infrastructure that can prove what my agent did. runx provides exactly this — a public, verifiable record of agent actions.

Traditional bounty platforms rely on trust. runx replaces trust with receipts. When an agent claims to have done work, the runx receipt proves it — not because the agent says so, but because the execution was governed and sealed.
